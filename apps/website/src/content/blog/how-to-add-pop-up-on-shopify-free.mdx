## Set up one popup before adding more automation

Shopify's Forms app is a practical first option for a basic popup. Create one focused form, add only the information the campaign needs, activate the form, and enable the Forms theme app embed. Shopify documents that popup forms require the theme app embed; it also supports device, page, and trigger controls. Follow [Shopify's create-form steps](https://help.shopify.com/en/manual/promoting-marketing/create-marketing/forms-app/create) and [popup settings](https://help.shopify.com/en/manual/promoting-marketing/create-marketing/forms-app/settings/popup) for the exact admin flow.

1. Write a short offer that accurately states what the subscriber receives.
2. Configure the appropriate marketing consent and any relevant disclaimer.
3. Show the form on one relevant page type before choosing site-wide display.
4. Test submit, dismiss, keyboard close, product options, and cart access on mobile.
5. Record form views, submits, and the follow-up action before changing the trigger or offer.

Shopify says merchants should send promotional content only to customers who have agreed to receive marketing. Its [contact-collection guidance](https://help.shopify.com/en/manual/promoting-marketing/create-marketing/customer-contact-information) is a useful operational reference, but it is not legal advice for a store's local requirements.
