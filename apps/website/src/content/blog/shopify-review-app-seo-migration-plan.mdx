1. Confirm the affected template, app, plugin, or feed output.
2. Check rendered HTML, canonical, sitemap, schema, internal links, and analytics events.
3. Save before evidence so a rollback is possible.
4. Ship the smallest useful fix and verify the live URL.

## FAQ

### What is the first step for Shopify review app SEO migration?

Start with the highest-risk page or template, then verify the visible output before changing anything.

### Should this be automated?

Automate repeatable checks after the rule is trusted. Keep human review for claims, redirects, schema, analytics, and anything that can remove useful content.

### How does this help AI search?

AI search systems need direct answers, clean entities, consistent links, and trustworthy source pages. A page that states the issue, shows the workflow, and avoids exaggerated claims is easier to summarize and cite.
