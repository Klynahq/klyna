1. Capture one test journey and note which platforms receive purchase events.
2. Search for hardcoded purchase scripts in theme and checkout-related areas.
3. Check GTM containers and installed apps for duplicate event triggers.
4. Keep one authoritative purchase path per platform unless deduplication is clearly configured.
5. Document the fix and re-test after each change.
