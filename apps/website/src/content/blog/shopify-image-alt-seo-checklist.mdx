## Workflow

1. Record the current storefront behavior before changing anything.
2. Duplicate or preview the theme if the app can affect layout or scripts.
3. Check whether the issue is content, UX, theme code, or app configuration.
4. Install or adjust one thing at a time.
5. Recheck mobile, speed, analytics, consent, and key product pages.
6. Document the rollback path before calling the change complete.

## Product-image audit that a merchant can complete

Audit one product type at a time instead of treating every image as the same task. List the primary product image, each variant image, lifestyle photography, and decorative theme assets separately. For each one, check whether the existing alt text describes what is actually visible and whether it helps a customer distinguish the image from the next one.

Shopify recommends brief, descriptive alt text and notes that its product-media editor can save suggested or manually entered descriptions. Google's image documentation says that image context, nearby text, and useful alt text all help it understand the subject of an image; it also warns against keyword stuffing. Use [Shopify's product-media instructions](https://help.shopify.com/en/manual/products/product-media/add-alt-text) and [Google's image SEO guidance](https://developers.google.com/search/docs/appearance/google-images) as the acceptance check, not a bulk tool's completion badge.

| Image group | Review question | Safe next action |
| --- | --- | --- |
| Main images | Can a shopper identify the product and visible material or color? | Add a concise, image-specific description |
| Variant images | Does the text distinguish the color, pattern, or view? | Keep the product reference and name the visible difference |
| Lifestyle images | Does it describe the product in the scene without inventing a benefit? | Use the setting only when it is visible and relevant |
| Decorative assets | Would a screen-reader user miss meaningful information without it? | Use empty alt text when the image is purely decorative |

Keep a short batch note with the product handles, date, editor, and sample URLs tested.
