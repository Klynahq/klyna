## FAQ

### Why is duplicate pixel tracking dangerous?

It can inflate reported conversions, distort ROAS, and train ad platforms on noisy events.

### Can Shopify Customer Events prevent all duplicates?

No. It helps manage registered pixels, but manual theme code or tag managers can still create overlap.

### Which official source should merchants understand?

Shopify explains its pixel manager in the <a href="https://help.shopify.com/en/manual/promoting-marketing/pixels/overview/">Pixels overview</a>.
