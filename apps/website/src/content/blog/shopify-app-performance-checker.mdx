## FAQ

### Is Shopify app performance checker only an app choice?

No. The app matters, but the stronger first step is diagnosing the store problem, expected user path, and cleanup risk.

### What should Klyna measure after this work?

Track non-brand impressions, indexed pages, product-page visits, downloads, installs, key events, and whether the affected Shopify page works better after changes.

### Should Klyna automate the fix immediately?

Not by default. The safest workflow is scan, explain, backup, fix, and recheck.

## A repeatable performance test

1. Capture the mobile experience before changing the theme or app settings.
2. Identify scripts, app embeds, pixels, and widgets loaded on the affected template.
3. Confirm which customer job each resource supports.
4. Disable one nonessential source in a duplicate theme and test the same path again.
5. Publish only when the customer journey and measurement still work.
