The Klyna Shopify app is an embedded app built on Remix and Polaris. It uses
the same audit engine as the WordPress plugin.

## From the App Store

1. Visit the Klyna listing on the Shopify App Store.
2. Click **Add app**.
3. Approve the requested scopes (read products, read content, write metafields).
4. The app opens inside your Shopify admin under **Apps → Klyna**.

## During the preview

While the public listing is under review, store owners can install via a direct
partner link. Email `support@klyna.dev` with your store's `myshopify.com`
domain and we send a one-time install URL.

## First run

The first time the app loads it indexes your products in the background. A
progress bar appears at the top of the dashboard. Indexing 1,000 products takes
roughly two minutes on a healthy store.

## Permissions

Klyna only ever requests the minimum scopes it needs. See
[Scopes and permissions](/help/shopify/scopes-and-permissions) for the full
list and what each one is used for.
