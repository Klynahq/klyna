The Klyna WordPress plugin runs on PHP 8.1 or newer and WordPress 6.4 or newer.
It works on single-site and multisite installs.

## From the .zip

1. Download the latest release from the [Downloads](/downloads) page.
2. In WordPress admin, go to **Plugins → Add New → Upload Plugin**.
3. Choose the `klyna.zip` file and click **Install Now**.
4. Click **Activate** when the install finishes.

You should now see a **Klyna** item in the admin sidebar with five subpages:
Dashboard, Audit, Internal Links, Schema, and Settings.

## Verify it loaded

Open any post in the block editor. The Klyna icon should appear in the top-right
sidebar toggles. If it does not appear, see
[Troubleshoot install](/help/wordpress/troubleshoot-install).

## Next steps

- Open **Klyna → Settings** and choose which schemas to emit.
- Optionally add a free AI key under **AI assistant**. See
  [Bring your own AI key](/help/getting-started/bring-your-own-ai-key).
- Run an audit on your highest-traffic post.
