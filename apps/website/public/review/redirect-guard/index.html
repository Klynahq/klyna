Klyna Redirect Guard review walkthrough

This public walkthrough shows the reviewer the core merchant workflow for Klyna Redirect Guard.

  1. Install Klyna Redirect Guard on a development store.
  2. Open the embedded app from the store admin.
  3. Approve the Starter test billing plan when prompted.
  4. Click Audit redirects on the dashboard.
  5. Open Fix playbook and enter an unused retired source path.
  6. Enter / as the safe live destination.
  7. Check the explicit review confirmation, then click Validate and create redirect.
  8. Confirm the redirect appears in Existing redirect map and Klyna change log.
  9. No separate Klyna account is required.
