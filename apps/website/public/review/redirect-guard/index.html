Klyna Redirect Guard walkthrough

This public screencast demonstrates onboarding and the core merchant workflow in the embedded Shopify app. No separate Klyna account is required.

Setup and test steps

  1. Install Klyna Redirect Guard on a Shopify development store.
  2. Open the embedded app from Shopify Admin.
  3. Approve the Starter test plan when prompted.
  4. Select Audit redirects to refresh the diagnostic report.
  5. Select Open redirect workspace on the dashboard.
  6. Review redirect-map risks, URL-loss monitoring, export, and guarded fixes.

Core features demonstrated

  • Redirect coverage diagnostics and saved scan history
  • A visible dashboard link to the Redirect workspace
  • URL-loss baselines and unprotected removal detection
  • Redirect chain and loop risk detection
  • Validated, explicitly confirmed redirect creation
  • CSV export and timestamped Klyna change history
