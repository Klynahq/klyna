# Klyna Cleanroom

## One-line positioning

Find old app code, duplicate pixels, and theme debris before it slows your Shopify store.

## App Store metadata

- Subtitle: Find leftover app code and duplicate tracking
- Search terms: theme cleanup, app code, duplicate pixel, script audit
- Category fit: Store design, Store management
- Pricing: Free plan available. Pro is $9/month with a 7-day trial.

## Merchant problem

Merchants uninstall Shopify apps but old scripts, snippets, app blocks, and tracking pixels often remain in the theme. They usually do not know what is safe to remove, and developer cleanup can become risky without evidence.

## Core features

- Storefront scan for common leftover app signatures.
- Duplicate Meta, Google, TikTok, Pinterest, and affiliate tracking warnings.
- External script stack count across sampled pages.
- Latest score, evidence, and next-step recommendations.
- Safe cleanup playbook built around backups, preview, and rollback.
- Pro scan history and downloadable CSV evidence reports.

## Pricing

- Free: three manual checks each month, latest findings, and the cleanup operating guide.
- Pro: $9/month for unlimited manual checks, up to 50 historical scans, and CSV evidence exports.
- Trial: seven days through Shopify Billing.

## Benefit statements

- See recurring app signatures before touching theme code.
- Spot possible duplicate tracking sources across sampled storefront pages.
- Give developers an evidence-backed cleanup queue with explicit rollback guidance.

## Review guardrails

Do not promise guaranteed speed gains. Do not auto-edit live themes. Any future cleanup workflow must duplicate the theme, show diffs, require confirmation, and keep rollback notes.
