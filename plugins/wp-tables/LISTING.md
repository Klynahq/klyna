## Long description

**Klyna Tables** turns plain WordPress content into clean, fast, responsive
tables — with live search, click-to-sort columns, and pagination — from one
lightweight, open plugin. Build a table by hand in a focused visual editor, or
import a CSV and let Klyna build the grid for you. Then drop it anywhere with a
shortcode or the **Klyna Table** block.

Everything runs on **your own server**. There are **no third-party APIs, no API
keys, and no jQuery** on the front end. Tables stay valid, readable HTML even
with JavaScript disabled.

### Why people use it

- **Visual builder, no spreadsheet wrestling.** Add columns and rows, set each
  column's type (text, number, link, image, HTML) and alignment, and you're done.
- **One-click CSV import.** Paste CSV or upload a `.csv` — quoted fields and
  embedded commas just work.
- **Drop it in anywhere.** `[klyna_table id="12"]` or the server-rendered
  block. Works in posts, pages, widgets, and full-site-editing templates.
- **Mobile-ready out of the box.** Wide tables scroll; on phones they stack into
  tidy, labelled cards.
- **Sell with it.** With WooCommerce active, `[klyna_products]` renders a product
  table with image, price, stock, and add-to-cart — columns of your choosing.
- **Fast and private.** Assets load only on pages that have a table, and all the
  interactivity runs in the browser with zero extra requests.

### Built by an indie studio

Klyna Tables is part of the [Klyna](https://klyna.dev) toolkit — open tools that
help your work get found. No dark patterns, no upsell wall in front of the
features that matter.
