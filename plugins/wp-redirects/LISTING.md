## Full Description

**Fix broken links before they cost you rankings.**

Klyna Redirects gives WordPress sites a complete redirect management system — a rules-based redirect engine, a live 404 monitor, and automatic 301 creation when post slugs change. Built clean, no bloat, no jQuery.

### Features

- **Redirect rules engine**: Exact match or regex. Supports 301 (permanent), 302 (temporary), 307 (method-preserved), and 410 (gone). Hit counter per rule.
- **404 monitor**: Every 404 logged with URL, referrer, and hit count — sorted by most-hit so you fix what matters first.
- **One-click from 404**: Enter a destination URL next to any 404 row and create a 301 in one click.
- **Auto-redirect on slug change**: When you rename a published post, Klyna Redirects automatically creates a 301 from the old URL. No manual step required.
- **Log pruning**: Old 404 entries pruned automatically via wp-cron (configurable retention window).
- **No external deps**: Everything stored in two custom tables in your own database.
