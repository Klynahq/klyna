## Long description

Most WordPress speed plugins quietly route you to a paid CDN, a paid image
service, or a "cloud optimizer." **Klyna Speed doesn't.** It does the
high-impact Core Web Vitals basics — full-page caching, lazy-loading, deferring
JavaScript, minifying CSS and HTML, preloading key assets, and taming the
Heartbeat API — and it does all of it locally, with zero external requests.

Turn it on and you get sensible defaults immediately: a disk-backed full-page
cache that serves static HTML on repeat visits, LCP-safe image lazy-loading,
deferred non-critical scripts, and minified output. Saving a post clears exactly
the pages that changed. One click purges everything.

It's part of the **Klyna** toolkit — an indie studio building open, modern tools
that help your work get found. No subscription, no account, no telemetry.

### What you get

- **Full-page disk cache** with smart, save-driven invalidation
- **LCP-safe lazy-load** for images and iframes
- **Defer JavaScript** with a safe denylist (jQuery core stays put)
- **CSS minification** of local stylesheets, cached to disk
- **HTML minification** that preserves your scripts and `<pre>` blocks
- **Preload hints** for the fonts and assets you choose
- **Heartbeat control** — slow it, scope it to the editor, or switch it off
- **One-click purge** from the dashboard, settings, or admin bar
- **No external requests. Ever.**

## FAQ snippets (store)

**Does it call any external services?** No — everything runs on your server.

**Will it work with my host's cache?** Yes; turn off Klyna's page cache and keep
the optimization features, or use Klyna's cache and disable the host one. Run
only one full-page cache.

**Will lazy-load hurt my LCP?** No — the first image on every page stays eager.

**Is it really free?** Yes. GPL-2.0-or-later, no paid tier, no account.
